Aplikasi sistem parkir sederhana berbasis bahasa Go yang digunakan untuk mengelola data petugas dan transaksi parkir kendaraan di sebuah mall. Program memiliki fitur login admin dan petugas, pengelolaan data petugas, pencatatan kendaraan masuk dan keluar, perhitungan biaya parkir berdasarkan jenis kendaraan dan durasi parkir, pencarian kendaraan berdasarkan nomor polisi, pengurutan data transaksi, serta pembuatan laporan total pendapatan parkir harian.
